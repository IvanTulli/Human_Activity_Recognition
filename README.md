This repository contains several projects having to do the with Human Activity Recognition with Smartphones dataset from Kaggle: https://www.kaggle.com/datasets/uciml/human-activity-recognition-with-smartphones

More specifically, we have:
- A folder containing the python scrip and additional files for a Streamlit app showing the prediction results for either pre-trained models, or models trained by the app.
- A folder containing Jupyter notebooks for several models for the associated classification problem.
- A folder containing Jupyter notebooks for several models for a clustering problem associated to the dataset.
