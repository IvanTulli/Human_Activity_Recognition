This folder contains the following files for the Streamlit app:
- The Python script for the app.
- A Jupyter notebook containing the code for the trained models used for the app, and an additional neural network model, which is not yet implemented in the app.
- 3 Pickle files for the pre-trained models used by the app.
- 1 Keras model for the trained neural network, not yet implemented in the app.
- 2 .csv files containing the train and test portions of the dataset.
- A .txt with the requirements for the app.
